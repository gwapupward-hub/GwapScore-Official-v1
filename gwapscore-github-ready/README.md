# GWAP Score

Trust Infrastructure Protocol v1.0

This repository contains:
- Public Trust Verification UI (Next.js)
- Telegram Bot Adapter (Webhook-based)
- Protocol-aligned architecture

## Packages
- /apps/ui        → Public verification site
- /apps/bot       → Telegram bot adapter
- /packages/core  → Trust protocol types (shared)

## Philosophy
- Append-only trust
- No mutable scores
- Explainable verification
- Platform-agnostic core

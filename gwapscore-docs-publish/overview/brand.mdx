# GwapScore Brand

Official brand assets and usage guidelines for GwapScore.

## Logo

The official GwapScore logo features a vibrant green pinching hand gesture, symbolizing precision and value assessment.

<img src="/logo.png" alt="GwapScore Official Logo" width="200" />

### Logo Files

The official logo is available in the following locations:
- Documentation: `/logo.png`
- Brand Assets: `/assets/brand/logo.png`
- Application Assets: `/gwap-score-full/assets/brand/logo.png`

### Brand Colors

**Primary Green**: `#00FF00` or `rgb(0, 255, 0)` or similar bright green
- Used for the main logo and primary brand elements
- Represents precision, trust, and value

### Usage Guidelines

#### Do's
- Use the logo on white or light backgrounds for optimal visibility
- Maintain the original aspect ratio when resizing
- Ensure adequate clear space around the logo
- Use the logo to represent official GwapScore products and services

#### Don'ts
- Do not modify the logo colors
- Do not distort or skew the logo
- Do not add effects or filters to the logo
- Do not use the logo on backgrounds that reduce visibility

### Logo Variations

The primary logo should be used in most contexts. For specific use cases:
- **Full Color**: Use on light backgrounds (primary usage)
- **White**: Use on dark backgrounds when needed
- **Icon Only**: Can be used as a favicon or app icon when space is limited

### Minimum Size

- **Digital**: Minimum width of 32px for icon usage, 120px for full logo
- **Print**: Minimum width of 0.5 inches

### File Formats

- **PNG**: For web and digital use (with transparency)
- **SVG**: For scalable applications and print (vector)
- **ICO**: For favicon usage

## Brand Voice

GwapScore represents trust, precision, and clarity in reputation assessment. Our brand voice is:
- **Professional**: We take trust seriously
- **Clear**: We communicate simply and directly
- **Innovative**: We're building the future of decentralized reputation
- **Inclusive**: We're building for everyone
